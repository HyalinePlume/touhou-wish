# 连抽汇总动画与素材说明

## 使用与流程

完成本轮最后一位角色的单独展示后，点击原有关闭按钮，进入汇总页。实际结果数量为 2～10 时显示；只有 1 位时维持原来的返回流程。汇总页不会再次抽奖或写入历史，顺序与逐个展示一致。部分抽取失败时，只展示已成功保存的结果。

点击右上角关闭、底部确定或按 Escape 返回首页，并恢复背景音乐。汇总页使用模态对话框，阻止误操作背景。桌面一行居中，手机竖屏超过五张自动分行。系统启用减少动态效果时，取消滑入和循环光效。

## 视频效果拆解与实现

参考：用户提供的「序列 02.mp4」（约 4.73 秒）。视频约 0.4 秒开始出现卡片，约 1.6 秒完成排列，随后保持卡片位置，循环播放装饰光效。视频中的直播边栏、重复角色补偿图标不属于此次功能。

| 层级 | 实现 |
| --- | --- |
| 背景 | 复用 bg-pic-pick.jpg，模糊、压暗并加中央淡光 |
| 整体排列 | 2～10 张等高细长卡片，用 flex 整体居中，数量影响宽度而不改变抽取顺序 |
| 滑入 | 首张延迟 100ms，后续每张错开 125ms；每张运动 620ms；从右侧屏幕外进入，前快后慢，轻微横向压缩恢复 |
| 速度感 | 滑动前段轻微模糊和提亮，落位前消除模糊；约运动 62% 时短暂闪白，随后恢复原色 |
| 边框 | CSS 多边形生成上下尖角轮廓，外层模糊辉光；按星级使用金、紫或蓝色 |
| 停留循环 | 上下柔光焰约 2.3/2.7 秒伸缩呼吸，边缘约 2.8 秒明暗变化，尖端星光约 2 秒闪烁 |
| 细节循环 | 每卡 8 个上浮粒子，生命周期错开；约 4.6 秒一次低强度斜向扫光 |
| 立绘 | 落位后保持位置、大小不动，仅独立装饰层运动 |

代码入口：`src/lib/components/WishSummary.svelte`。`step`、`entrance` 控制节奏，CSS 的 `.arrival` 控制宽高，`.flame`、`.particles`、`.sheen` 分别控制停留光效。页面衔接在 `src/routes/+page.svelte` 的 `handleCloseResult` / `finishResults`。

## 现有素材与后续可选处理

当前全部使用现有角色 PNG、种族图标和背景，光效由代码生成，无需新增素材即可使用。现有整身立绘直接通过 `object-fit: cover` 裁切，不会修改原图。不同姿势可能导致脸部偏离窄卡中心，这需要后续逐角色调整。

为了进一步接近视频，建议：

1. **角色卡面构图**：另存一份透明 PNG/WebP，建议 300×1000 或 360×1200。统一头部落在上方 15%～35%、胸像居中，下方 25% 预留名字和种族图标。不要把文字或边框烘焙进图；保留原始全身立绘给单独展示使用。若继续使用原图，也可为角色提供裁切中心位置，再接入现有 `summaryPosition` 参数（默认 `50% 18%`）。目前抽取结果没有专用卡面字段，交付专用卡图后再添加映射。
2. **更自然的光焰（可选）**：现在是 CSS 渐变近似。若希望达到视频中不规则流动的火焰细节，可制作 1.5～2.5 秒无缝循环、透明底的光焰 WebM 或 PNG 序列，建议 256×512，中心亮、边缘自然透明，上下各留足淡出空间。只画光，不含角色、边框或背景；可用白色光焰统一着色。素材准备后需将当前 `.flame` 层接成动画素材。
3. **装饰边框（可选）**：若要更精细的雕花轮廓，提供透明 SVG 或约 300×1000 的 PNG；保留中间透明区域。现在尖角轮廓由 CSS 直接绘制。

不需要提前合成每张卡片的视频；立绘和光效保持分层即可。

## 验证

`npm run build` 构建检查；`tools/verify-summary.cjs` 使用 Playwright + Edge 在独立浏览器上下文中验证，不读取用户浏览器历史。

已覆盖单抽及 2、5、10 连抽、角色顺序、历史条数、三种关闭方式、再次抽取、桌面居中、手机可见范围、减少动态效果、停留时立绘位置不变和浏览器运行错误。

验证工具需要可解析的 Playwright；本机可设置 `PLAYWRIGHT_MODULE` 为已安装 Playwright 的目录，然后执行 `node tools/verify-summary.cjs`。截图输出至 `artifacts/summary-*.png`。
